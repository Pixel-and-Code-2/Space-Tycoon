### Физический кубик рандома (галочка в настройках)

Кидаем **только при расчёте выстрела**.

Модельки: `DND_CUBES`. D20 пока нет в движке → в формуле где нужен d20 временно **d10×2** (заглушка), потом вернуть D20.

**Пол для кубика (анти-провал)**

- один раз завести невидимый BoxCollider / Plane на уровне пола (слой под physics кубика)
- высота пола — **одна настройка**; камера/прочее только читают/меняют эту высоту, а коллайдер двигается за ней
- не плодить отдельный «пол» внутри CameraSettings как второй источник истины

**Физика**

- кидать в сцену с коллизиями (пол + окружение)
- упрощённые режимы — запасной план

**Чтение грани → число**

- алгоритм «какая локальная ось/нормаль ближе к world up» + threshold (ребро / угол)
- **маппинг грань→число — per prefab/тип кубика** (d6, d10, d20…): у каждого свой `DiceFaceMap` / разметка в инспекторе (нормаль грани → value). Универсальной магии «для всех мешей одинаково» нет — ориентация UV/меша разная
- d10×2 = два независимых чтения (или один компонент на каждый куб)

**Результат в UI**

- world-`ShowMessage` в точке броска
- суперкрит — жёлтый; ultimate (угол) — красный

**Skip**

- Esc / Enter → импульс вниз ~0.2 с → тот же read верхней грани

Отключается галочкой в настройках.

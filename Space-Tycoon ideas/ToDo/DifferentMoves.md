## Реализовано в коде

- `TurnManager`: очередь `RoundQueue`, `CurrentActor`, инициатива = параметр ловкости (`SPD` по умолчанию) + `Random(0..initiativeRandomMax)` — **только при входе в бой** (порядок кругов дальше тот же).
- Кнопка пропуска хода (`EndPlayerTurn`) завершает ход **только текущего** игрока; враг завершает ход через `EndEnemyTurn` после своего AI-сценария.
- На ходе игрока нельзя перевыбрать другого персонажа.
- `SimpleEnemyAI` строит сценарий только для `CurrentActor`.
- UI: `TurnOrderUI` + префаб `TurnOrderIcon` (маленькая/большая картинка).

## Инструкции для Unity Editor

### 1. Префаб иконки хода (`TurnOrderIcon`)

1. Создай UI Prefab, например `Assets/.../TurnOrderIcon.prefab`.
2. Корень: `RectTransform` + `Button` + компонент `TurnOrderIcon`.
3. Два дочерних объекта (оба с `Image`):
   - `Small` — обычный размер
   - `Big` — увеличенный размер (ход текущего персонажа)
4. В `TurnOrderIcon` проставь:
   - `Small Icon` → объект Small
   - `Big Icon` → объект Big
   - `Small Image` / `Big Image` → их `Image`
   - `Button` → Button на корне
5. По умолчанию в префабе активен Small, Big выключен (код сам переключает).

### 2. Полоса очерёдности на GameUI

1. На канвасе GameUI сверху создай панель (Horizontal Layout Group + Content Size Fitter по желанию).
2. Повесь на панель (или рядом) компонент `TurnOrderUI`.
3. Проставь:
   - `Icons Parent` → контейнер с Horizontal Layout (куда инстанцируются иконки)
   - `Icon Prefab` → префаб из п.1
   - `Default Player Sprite` / `Default Enemy Sprite` — запасные спрайты
   - `Root Panel` → панель, которую скрывать вне боя (можно тот же объект)

Враги **не** кладутся вручную в сцену UI: при старте боя / спавне `TurnOrderUI` инстанцирует префаб под каждого в очереди.

### 3. Портреты персонажей (опционально)

На префаб/объект пешки (`PawnBrain`) добавь `TurnOrderPortrait` и укажи `Portrait`.  
Если нет — возьмутся default sprite’ы из `TurnOrderUI` (игрок/враг).

### 4. Настройки инициативы на `TurnManager`

В инспекторе TurnManager:

- `Agility Parameter Key` — ключ параметра ловкости в данных пешки (сейчас по умолчанию `SPD`; когда появится отдельная ловкость — поменяй ключ)
- `Initiative Random Max` — верхняя граница рандома, добавляемого к ловкости
- `Default Agility` — если параметра нет

Формулы для инициативы **не** используются.

### 5. Поведение в Play Mode (проверка)

1. Войди в боевой триггер → сверху должна появиться полоса иконок, отсортированная по инициативе.
2. Текущий ход — большая иконка.
3. Клик по иконке — камера фокусируется на пешке (`CameraTargetController.FocusOnLookTarget`).
4. На ходе игрока нельзя выбрать другого; после действий нажми Skip/EndTurn → ход следующему в очереди.
5. На ходе врага AI ходит только этим врагом, затем очередь идёт дальше.
6. Выход из боя — полоса скрывается.

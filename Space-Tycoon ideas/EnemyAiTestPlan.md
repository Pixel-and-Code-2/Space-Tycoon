# Тест ИИ врагов по GDD

## Термины в коде

| Роль в коде | Кто это | Префаб/пример |
|-------------|---------|----------------|
| **Melee** | маленькие ближники (UFO normal/big) | `EnemyNormal`, `EnemyBig` |
| **Tank** | жирный танк | `EnemyTank` |
| **Shooter** | дальнобой | `EnemyShooter` |

**Танк ≠ Melee.** Танк — отдельная роль (`DecideTank`: к ближайшему, бить). Melee — логика из GDD «ближник» (приоритеты %, стамина, 2 удара).

## Пресеты (`Assets/Resources/EnemyAI/`)

| Пресет | Когда |
|--------|--------|
| `Ai_Melee_Start` | стартовый модуль |
| `Ai_Melee_Living` | жилой до карантина |
| `Ai_Melee_Hard` | энерго / карантин / наука |
| `Ai_Shooter_Living` | жилой до карантина |
| `Ai_Shooter_Energy` | энергомодуль |
| `Ai_Shooter_Quarantine` | карантин + наука |
| `Ai_Tank` | танк всегда (override на префабе) |

На `SimpleEnemyAI` уже стоят `stageRules` по frontier main-таска. Для ручного теста в стартовой комнате — **override на каждом враге**.

## Пошаговый ручной тест (все типы в стартовой комнате)

1. Выдели врага → `PawnDataController` → **Ai Profile Override**.
2. Выставь пресет «как будто другая локация» (таблица ниже).
3. Сохрани сцену / Play.
4. Вступи в триггер, дай врагу ход, смотри поведение.

### Чеклист Melee (маленький)

| Override | Ожидание |
|----------|----------|
| `Ai_Melee_Start` | всегда бежит к цели, бьёт **1** раз, даже с помехой |
| `Ai_Melee_Living` | цели ~50% Заяц / 30% пистолет / 20% винтовка; стамина&lt;50 → только сближение; без движения → 2 удара; после движения → ~45% |
| `Ai_Melee_Hard` | цели ~40% винтовка / 30% Заяц / 30% пистолет; после движения / с помехой → ~60%; добивание ≤50% HP |

### Чеклист Shooter

| Override | Ожидание |
|----------|----------|
| `Ai_Shooter_Living` | приоритет винтовка=пистолет &gt; Заяц; на ~5 м — **1 выстрел и отход**; 1–4 м — отход/милиш; шансы ~45% |
| `Ai_Shooter_Energy` | винтовка=Заяц &gt; пистолет; шансы ~55% |
| `Ai_Shooter_Quarantine` | Заяц &gt; винтовка &gt; пистолет; шансы ~60% |

### Чеклист Tank

| Override | Ожидание |
|----------|----------|
| `Ai_Tank` | к ближайшему союзнику, удар в милише; без «умных» % приоритетов GDD ближника |

## Авто-stage (без override)

| Frontier (первый не-Done main) | Melee | Shooter |
|--------------------------------|-------|---------|
| &lt; 2 | Start | Living |
| &lt; 6 | Living | Living |
| &lt; 9 | Hard | Energy |
| иначе | Hard | Quarantine |

Чтобы проверить stage: сбрось override, прогони сейв с разным прогрессом main-тасков.

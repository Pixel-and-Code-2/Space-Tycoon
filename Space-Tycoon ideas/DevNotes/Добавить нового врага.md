# Добавить нового врага

Враги — варианты [[Pawn.prefab]] с `selectableType = Enemy`, layer 9 (root), 10 (модель).

## 1. Статы

1. Duplicate `Assets/Resources/EnemyTvar Small.asset` → новое имя (например `EnemyTvarShooter`).
2. В `mustHaveParameters[0]` подставить **weapon asset** (как у людей в `PlayerGusev` → `WeaponTKBK`), не melee `WeaponClaw`.
3. Для стрельбы скопировать поля из `WeaponTKBK`: MINDMG, MAXDMG, ACC, MAG, TotalAmmo, ROF.

Пример: `WeaponEnemyShooter.asset` + `EnemyTvarShooter.asset`.

## 2. Префаб

1. Duplicate `EnemyNormal.prefab` → `EnemyShooter.prefab`.
2. Удалить child UFO-модель, вложить FBX (`ENEMY_SHOOTER_ANIM`).
3. Transform: `y = -0.84`, rotation **identity** (без 180°).
4. `PawnDataController.initialPawnData` → новый asset.
5. `Animator` + `PlayerController` (если клипы `4_IDLE`/`1_MOVE`/…) + `AnimatorBrainPlayer`.
6. `PawnBrain`: shoot/reload/noAmmo sounds; `defaultMaterial`/`selectedMaterial` = материал меша.
7. Layer 9/10 как у `EnemyNormal`.

## 3. ИИ

`SimpleEnemyAI.AddPawnToScenario(pawn)` добавляет Move/Wait/Melee. **Стрельбу ИИ не трогаем** — отдельная задача.

Подробнее про постановку: [[Поставить врага на сцену]].

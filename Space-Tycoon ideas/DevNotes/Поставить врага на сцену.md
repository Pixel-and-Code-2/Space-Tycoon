# Поставить врага на сцену

Есть три типичных случая. Общее: prefab должен быть готов по [[Добавить нового врага]].

---

## A. Статически в зоне (стартовая локация)

1. Instance префаба под группой вроде `Enemies_lvl1`.
2. **TurnManager** (`MainComponent`): `listOfTriggers[N].enemies` — добавить `PawnBrain` этого врага (тот же trigger, что соседние `Enemy1.1`).
3. **SimpleEnemyAI** (`MainComponent`): в `scenario` нужна запись `controlledPawn` + `capability: Move` (0). Проще: `AddPawnToScenario(pawnBrain)` в editor script — добавит Move/Wait/Melee.
4. **WarFog**: на объекте-сетке тумана (например `M_0_P2`) компонент `WarFog` → `othersToInclude` — добавить **GameObject root врага** (как уже лежат `Enemy1.2` рядом). Без этого враг не скрывается туманом — см. `WarFog.RegisterRenderersUnder` в `Assets/Scripts/WarFog/WarFog.cs`.

---

## B. Delayed spawn (триггер, часто «в воздухе»)

1. На сцене Transform-точки `Pos1`, `Pos2`, … (пустые GO).
2. **TurnManager** → `listOfDelayedTriggers[i].enemySpawnPoints[]`:
   - `enemy` — prefab (не scene instance)
   - `where` — Transform точки
3. При входе в зону / `StartDelayedEncounter` → `Instantiate(enemy, where.position, where.rotation)` (`TurnManager.SpawnFromRegistryEntry`).
4. Спавненный враг автоматически: `trigger.enemies.Add`, `SimpleEnemyAI.AddPawnToScenario`.
5. **WarFog для delayed**: обычно враг появляется уже **внутри открытой зоны боя** — отдельный `othersToInclude` не нужен, если коллайдер тумана уже снят. Если спавн **вне** видимости до боя — добавить prefab-root в `othersToInclude` зоны, как в варианте A.

---

## C. Чеклист после постановки

- [ ] Виден / скрыт туманом корректно
- [ ] Есть в `listOfTriggers` или spawn point
- [ ] Есть в `SimpleEnemyAI.scenario` (для статических)
- [ ] NavMesh: стоит на полу, не T-pose (Animator controller назначен)
- [ ] Ходит лицом вперёд (rotation модели = identity, если FBX новый)

См. также [[Заменить модельку персонажа]], [[PawnBrain выделение материалом]].
